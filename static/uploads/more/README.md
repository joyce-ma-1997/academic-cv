# More About Me photos

Place your six photos in this folder with these names:

- photo-1.jpg
- photo-2.jpg
- photo-3.jpg
- photo-4.jpg
- photo-5.jpg
- photo-6.jpg

The matching placeholder disappears automatically when its photo is added.
Photos display left to right in two rows of three on desktop, two columns
on tablets, and one column on phones. They are cropped to a 4:3 frame.

For PNG or WebP images, use the correct filename extension and update the
matching `image` field in content/more.md. Do not simply rename a PNG
file to .jpg. Add descriptive `alt` text and optional captions in that file.

Edit the introduction below the closing `---` in content/more.md.
